호갱 API 사용법

치지직 후원을 이치방쿠지, 룰렛, 뽑기권과 연결해 방송 화면에 표시합니다. 아래 순서대로 설정하면 됩니다.

1. 로그인과 방송 연결

  1. 관리자 화면에서 네이버 계정으로 로그인을 누릅니다.
  2. 후원을 받는 치지직 스트리밍 채널과 연결된 네이버 계정으로 로그인합니다.
  3. 치지직 연결에서 채널명과 연결 상태가 정상인지 확인합니다.
스트림키는 필요하지 않습니다. 관리자 페이지도 방송 내내 열어둘 필요가 없습니다. 서버가 연결된 치지직 채널의 후원 이벤트를 계속 수신합니다.

2. 방송 전 확인

방송 전 점검에서 치지직 연결, 진행 중인 회차와 OBS 준비 상태를 확인합니다. 실제 내역을 변경하지 않는 오버레이 테스트도 이 화면과 오버레이 메뉴에서 실행할 수 있습니다.

3. 이치방쿠지

  1. 회차 설정에서 회차 이름과 장당 가격을 입력합니다.
  2. 상품별 등급, 상품명, 사진과 수량을 등록한 뒤 회차를 시작합니다.
  3. 시청자가 설정 금액을 후원하면서 원하는 번호를 메시지에 입력합니다. 예: 3번
  4. 정상 배정되면 번호판과 당첨 애니메이션에 즉시 반영됩니다.

이미 판매된 번호, 범위를 벗어난 번호, 금액 불일치는 처리 필요 항목으로 남습니다. 자동 환불은 지원하지 않습니다.

4. 후원 룰렛

  1. 후원 룰렛에서 최소 후원 금액과 항목별 가중치를 설정합니다.
  2. 시청자가 설정 금액 이상을 후원하면서 !룰렛을 입력하면 룰렛이 실행됩니다.
  3. 후원 등록 기능을 켠 경우 설정된 등록 금액과 !등록 항목명으로 새 항목을 추가할 수 있습니다.

가중치 비율은 룰렛 목록에 당첨 확률로 표시됩니다.

5. 뽑기권

  1. 뽑기권에서 이름, 후원 명령어, 정확한 후원 금액을 설정합니다.
  2. 각 항목에 사진, 항목명, 설명과 수량을 등록합니다.
  3. 수량 비례는 남은 개수에 따라 확률을 자동 계산하고, 직접 확률은 항목별 퍼센트 합계를 100%로 설정합니다.
  4. 시청자가 설정한 금액을 정확히 후원하면서 설정 명령어를 입력합니다. 예: !뽑기
  5. 남아 있는 항목 중 하나가 추첨되고 해당 항목 수량이 1개 차감됩니다.
수량이 0이 된 항목은 같은 뽑기에서 다시 나오지 않습니다. 모든 수량이 소진되면 뽑기권은 자동 종료됩니다.

6. OBS 오버레이 설정

  1. 관리자 오버레이 메뉴에서 필요한 OBS 주소의 복사 버튼을 누릅니다.
  2. OBS에서 브라우저 소스를 추가하고 복사한 주소를 붙여 넣습니다.
  3. 소스 크기는 1920 × 1080으로 설정합니다.

쿠지 번호판·당첨 애니메이션, 룰렛·룰렛 목록, 뽑기권 결과·뽑기권 목록은 각각 별도 주소입니다. 상품이나 항목을 변경해도 OBS 주소를 다시 입력할 필요 없이 자동 반영됩니다.

7. 효과음과 TTS

오버레이 메뉴에서 효과음과 Google Cloud TTS를 각각 켜거나 끌 수 있습니다. 테스트 버튼은 실제 판매, 추첨 수량과 결과 기록을 변경하지 않습니다.

8. 기록과 종료

이치방쿠지는 회차별 당첨 내역을, 룰렛과 뽑기권은 최근 결과를 각각 확인할 수 있습니다. 방송이 끝나면 진행 중인 회차나 뽑기권을 종료하세요. 처리 필요 항목은 확인 후 개별 또는 일괄 처리할 수 있습니다.

문제가 생겼을 때

연결 상태가 재연결 중일 때

일시적인 네트워크 문제일 수 있습니다. 잠시 기다린 뒤 치지직 연결에서 상태를 새로 확인합니다.

재인증 필요가 표시될 때

후원을 받는 스트리머 계정으로 네이버 로그인을 다시 완료하면 연결이 복구됩니다.

OBS 화면이 갱신되지 않을 때

OBS 브라우저 소스를 한 번 새로고침합니다. 평소 설정과 목록 변경은 최대 10초 이내 자동 반영됩니다.
